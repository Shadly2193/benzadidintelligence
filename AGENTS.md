## ⚠ LOCKED COLOR SYSTEM — DO NOT CHANGE

This website uses **V8 Midnight Magma** colors. These are final and must never be changed:

| Token | Value | Role |
|---|---|---|
| `brand-black` | `#0a0603` | Background (deep brown-black) |
| `brand-orange` | `#FF6A00` | Primary accent, buttons, labels |
| Deep ember | `#C83205` | Button gradients, borders |
| Hot ember | `#F06400` | Glitch, gradients |
| `brand-gray` / text | `#FFF0E0` | Warm white text |
| `brand-gray-text` | `#C8906A` | Secondary text |

Body background = `radial-gradient(ellipse 55% 100% at 0% 50%, rgba(200,50,5,0.55) 0%, transparent 55%), radial-gradient(ellipse 55% 100% at 100% 50%, rgba(240,100,0,0.35) 0%, transparent 55%), #0a0603`

**If the browser shows purple/neon/blue colors, it is a browser cache issue — NOT a code problem. Fix: kill node.exe, delete .next, restart server. Never edit globals.css to fix visual color issues.**
